# src/desktop/

Electron 28 desktop wrapper around the Angular SPA in [../frontend/ulp-web/](../frontend/ulp-web/). Same UI, native window. Phase 4 polish.

| Folder | Purpose |
|---|---|
| [ulp-desktop/](ulp-desktop/) | Electron main + preload + packager config |

## Why desktop?

CHA staff and accountants in some markets prefer a native window over a browser tab — better window management, system-tray notifications, drag-drop file uploads from OS. Same Angular SPA, different shell.
