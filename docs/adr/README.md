# Architecture Decision Records

One file per decision. Format: `NNNN-short-title.md` where `NNNN` is zero-padded sequence.

Template:

```markdown
# ADR NNNN — Title

**Status:** Proposed | Accepted | Superseded by ADR NNNN
**Date:** YYYY-MM-DD
**Decider:** Shankar

## Context
What problem are we solving? What constraints apply?

## Decision
What did we decide?

## Consequences
What's better, what's worse, what's now possible/impossible?

## Alternatives considered
Brief — what we rejected and why.
```
