# Sea Cargo Manifest and Transhipment Regulations (SCMTR) for ULP

## When this skill triggers
Working on SCMTR Arrival/Departure Manifest filing, PCIN/MCIN/CSN identifier generation, stuffing/stripping messages, ICEGATE MFTP submission, JSON manifest construction, or any code in `Backend/M4.SCMTR/`.

## Top 3 reference sources
1. **icegate.gov.in/new-initiatives/scmtr** (https://www.icegate.gov.in/new-initiatives/scmtr) — Official SCMTR portal. Authoritative for registration, message types, filing procedures.
2. **icegate.gov.in/sites/default/files/2022-02/FAQ_Sea_Cargo_Manifest_and_Transhipment_Regulations_2.0.pdf** — Comprehensive FAQ covering all message types, stakeholder responsibilities, JSON schema notes, MIG (Message Implementation Guidelines).
3. **CBIC Circular 16/2026 + Notification 31/2026** (https://www.cbic.gov.in/) — Latest SCMTR implementation guidance; transitional provisions extended to 30 June 2026.

## Critical ULP patterns

### SCMTR overview
```
What it is:
- Replaces Import Manifest (Vessels) Regulations 1971 + Export Manifest Regulations 1976
- Notified via Notification 38/2018 (11 May 2018), implemented in phases
- Mandatory electronic filing via ICEGATE
- All declarations submitted as JSON files

Status (May 2026):
- Import/Export Manifest messages: LIVE pan-India
- Stuffing messages (SF): LIVE since 25 Sep 2025
- Stripping messages (ST): in progress
- Inland transhipment messages: under development
- SEZ API integration: target 31 March 2026
- Transitional provisions: extended to 30 June 2026

Stakeholders that must register on ICEGATE for SCMTR:
- Authorized Carriers (vessel operators)
- Sea Agents
- Custodians (CFS/ICD/Terminal Operators)
- Terminal Operators
- Shipping Lines / NVOCCs
- Freight Forwarders / Consolidators
```

### Key identifiers (ULP master must track these)
```
PCIN — Primary Cargo Identification Number
   - Generated by Customs Automated System
   - Filed by Freight Forwarder on Master BL + House BL
   - Identifies a "freight forwarder consignment"
   - One PCIN = One House BL

MCIN — Master Cargo Identification Number
   - Generated by Customs Automated System
   - Generated against the Master BL declared by vessel operator
   - One MCIN = One Master BL (may include multiple PCINs/HBLs)

CSN — Consignment Summary Notice
   - Filed by freight forwarder
   - Quotes Master BL (issued by vessel operator)
   - Contains House BL details (issued to importer/exporter)
   - Returns PCIN

VCN — Voyage Call Number
   - Assigned by port for each vessel arrival
   - Vessel operator applies for this first
   - Required before manifest filing
```

### Manifest message types
```
Sea Arrival Manifest (SAM)
   - Filed by vessel operator
   - Before vessel arrival at gateway port
   - Contains list of all MCINs

Sea Departure Manifest (SDM)
   - Filed by vessel operator
   - Before vessel departure from gateway port
   - Contains list of all PCINs/MCINs being exported

Cargo Arrival Manifest (CAR)
   - To replace older messages
   - Filed by freight forwarder/sea agent
   - At cargo arrival

Stuffing (SF) - LIVE since 25 Sep 2025
   - Filed by Custodian/Terminal Operator
   - For each container being stuffed
   - Lists PCINs/MCINs being stuffed into the container

Stripping (ST) - in progress
   - Filed by Custodian/Terminal Operator
   - For each container being stripped
   - Lists PCINs/MCINs being stripped out

Other messages:
- ATE (Actual Time of Entry of conveyance) - by Terminal Operator
- ELR (Estimated Loading Report) - by Terminal Operator
- Amendment messages (parent + adjustment)
- VCN amendments
- Cancellation/suspension/extension of registration
```

### ICEGATE MFTP submission flow
```
MFTP = Managed File Transfer Protocol (SFTP-based)

Setup:
1. Register on ICEGATE -> get ICEGATE ID + private key
2. Configure MFTP with public key authentication
3. SFTP host: mftp.icegate.gov.in (port 22)
4. Upload directory: /upload/<ICEGATE_ID>/
5. Download directory: /download/<ICEGATE_ID>/

ULP filing flow:
1. Generate JSON message (validate against MIG schema)
2. Compute SHA-256 hash; store with audit log
3. SFTP PUT to /upload/<ICEGATE_ID>/<MessageType>_<Timestamp>.json
4. Wait for acknowledgement file in /download/
   - On success: <MessageType>_<Timestamp>_ACK.json
   - On error: <MessageType>_<Timestamp>_ERR.json with error codes
5. Update ULP message tracking with status

Polling: cron job every 5 min to check /download/ for acknowledgements.
```

### ULP schema (database)
```sql
CREATE TABLE m4_scmtr_message (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  tenant_id INT NOT NULL,
  message_type VARCHAR(10) NOT NULL,  -- SAM|SDM|SF|ST|...
  filer_type VARCHAR(30) NOT NULL,
  reference_id VARCHAR(50) NOT NULL,  -- VCN | container_no | PCIN
  payload_json JSON NOT NULL,
  payload_hash VARCHAR(64) NOT NULL,
  filing_date DATETIME NOT NULL,
  status ENUM('Drafted','Submitted','Acknowledged','Errored','Amended') NOT NULL,
  ack_filename VARCHAR(255),
  ack_received_at DATETIME,
  error_codes JSON,
  related_pcin_list JSON,
  related_mcin_list JSON,
  created_at DATETIME NOT NULL,
  INDEX idx_tenant_message (tenant_id, message_type),
  INDEX idx_filing_date (filing_date),
  INDEX idx_reference (reference_id)
);

CREATE TABLE m4_scmtr_pcin (
  pcin VARCHAR(50) PRIMARY KEY,
  tenant_id INT NOT NULL,
  master_bl_number VARCHAR(50),
  house_bl_number VARCHAR(50),
  shipper VARCHAR(255),
  consignee VARCHAR(255),
  status ENUM('Active','Stuffed','Loaded','Discharged','Stripped','Delivered') NOT NULL,
  current_mcin VARCHAR(50),
  current_container_no VARCHAR(20),
  generated_date DATETIME NOT NULL
);
```

## Critical gotchas

### Hapag-Lloyd / Maersk / MSC integration patterns (carriers)
- Carriers expect SI (Shipping Instructions) BEFORE filing.
- Forwarders/Consolidators must file CSN and update on ODeX or vendor-specific portal.
- PCIN must NOT be reused across different BLs.
- PCIN must be linked to Sea Departure Manifest (SDM).

### Bond registration mandatory
- SOC (Shipper Owned Container) operators must register their BOND under SCMTR.
- NVOCCs must register their consolidator BOND.
- Console agents must register their BOND.
- ULP master: track bond_no per carrier; alert on expiry.

### Amendment vs cancellation
- Errors in filed manifest: file an Amendment (parent + adjustment).
- Cancel only allowed before customs assessment begins.
- Future enhancement: Parent Amendment functionality.

### Inland transhipment messages still in development
- Currently NOT implemented in SCMTR (under development).
- During transition: continue old IGM/EGM for inland transhipment.
- ULP M4 must support BOTH old + new during transition (until 30 June 2026 latest).

### SEZ integration target 31 March 2026
- DG Systems onboarding SEZ units via API.
- ULP customers operating in SEZ must register for SCMTR module.

### Acknowledgement is asynchronous
- ICEGATE doesn't return acknowledgement synchronously.
- Acknowledgement comes as a separate file in /download/.
- Wait time: typically minutes; sometimes hours during high load.
- ULP polling job + status dashboard.

### Error codes are critical
- Every error code has a remediation procedure.
- Common errors:
  - Invalid VCN
  - PCIN reused across BLs
  - Container number format invalid
  - Stuffing exceeds container capacity
- ULP must maintain error code -> remediation lookup.

### Weekly outreach programs
- CBIC mandates weekly outreach by Chief Commissioners.
- ULP CHA users may attend; track these for compliance updates.

### File size + naming conventions
- JSON files: max 5 MB typical.
- Filename: `<MessageType>_<FilerICEGATEID>_<UniqueTimestamp>.json`
- Hash file: same name + `.hash` extension (SHA-256).
