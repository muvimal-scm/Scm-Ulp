1. Introduction

1.1 Purpose

M4-US is the United States compliance plugin for the ULP M4 (CHA / Customs) module. It implements US Customs and Border Protection (CBP) filing workflows via the Automated Broker Interface (ABI), Automated Export System (AES), and integrates with Partner Government Agency (PGA) portals.

1.2 Scope

CBP entry filing: types 01 (Consumption), 02 (Quota), 03 (AD/CV), 06 (FTZ), 11 (Informal), 23 (TIB)

Form 7501 entry summary preparation, calculation, submission

Authority to Make Entry (ATM) workflow

Immediate Transportation (I.T.) and in-bond movements

AES export filing (EEI - Electronic Export Information)

Importer Security Filing (ISF / 10+2)

PGA holds: FDA, USDA APHIS, EPA, FCC, FWS, ATF integration

US Customs Hold and Exam Notice handling

FIRMS Code lookup and validation

Letter of Guarantee, Delivery Order, Release Instructions document generation

Bond management (Single Transaction Bond, Continuous Bond)

Duty, MPF, HMF computation

1.3 Out of scope

Drawback claims (separate module M15-US planned for v2.1)

Reconciliation entries (separate workflow planned for v2.2)

CBP Form 28/29/4647 dispute workflows (manual handling for v2.0)

First Sale rule advanced computations (Phase 2 enhancement)

1.4 Relationship to M4-Core

M4-Core (country-agnostic) handles: shipment lifecycle, MBL/HBL tracking, document storage, basic customs entity model. M4-US extends M4-Core via the IComplianceProvider interface defined in the Internationalization Guide.

Activation: 

M4-US loads when tenant.country_code = &quot;US&quot; and tenant.compliance_plugins includes &quot;us-cbp-abi&quot;.

2.3 Filing flow (high-level)

    1. Carrier transmits Manifest (MOM/AMS) to CBP

    2. ULP receives manifest data via INTTRA / direct carrier feed

    3. Broker (ULP user) creates entry, classifies goods, computes duty

    4. ULP transmits SE to CBP via ABI

    5. CBP responds: Released / Hold / Exam

       - If Hold: ULP shows hold reason; broker resolves

       - If PGA Hold (FDA, USDA): broker files PGA data

    6. After cargo released, broker files SO (7501 entry summary)

    7. Duty payment via Periodic Monthly Statement (PMS) or per-entry

    8. CBP issues Liquidation notice (typically 314 days post-entry)

5.1 Duty calculation methods

Method

When used

Duty = Value × Rate%

Most common; e.g., apparel 16.5%

Specific

Duty = Quantity × $/unit

e.g., footwear $0.84/pair

e.g., footwear 12% + $0.84/pair

Other

5.2 Customs value (entered value)

Per 19 USC 1401a, transaction value (price actually paid or payable) is the primary basis. Adjustments per 1401a(b):

ADDED to price: packing costs, selling commissions, assists, royalties, proceeds of subsequent resale to seller, foreign inland freight, foreign loading

NOT INCLUDED: international freight, marine insurance, US destination charges (if separately billed)

Currency: convert to USD using CBP-published exchange rate for the date of export

    // Pseudo-code for entered value computation

    public Money ComputeEnteredValue(EntryLine line)

    {

        var basePrice = line.InvoicePriceUsd;       // converted from invoice currency

        var adds = line.PackingCosts + line.SellingCommissions

                 + line.Assists + line.Royalties

                 + line.ForeignInlandFreight + line.ForeignLoading;

        var deducts = 0m;  // none for transaction value method

        return Money.Usd(basePrice + adds - deducts);

    }

5.3 Merchandise Processing Fee (MPF)

Entry value

MPF amount

Formal entry (&gt;$2,500)

0.3464% of entered value, min $32.71, max $634.62 (FY2026 rates)

Informal entry ($800-$2,500)

$2.62, $6.53, or $9.99 depending on type

De minimis (&lt;$800)

Exempt

Note: 

MPF rates change annually (typically October 1). M4-US must read current rates from m4us_mpf_rate table; never hardcode.

5.4 Harbor Maintenance Fee (HMF)

Applies to: imports arriving by ocean vessel through US ports (and some IT moves)

Rate: 0.125% of entered value

Does NOT apply to: air, road, rail imports; US Virgin Islands; some Alaska/Hawaii movements

5.5 Anti-dumping (ADD) and Countervailing (CVD)

ADD/CVD cases are administered by Department of Commerce. M4-US must:

Maintain table of active ADD/CVD cases with effective rates per manufacturer

Match entry line&apos;s HTS + country + manufacturer to applicable case

Apply ADD/CVD on TOP of normal duty

Cash deposit at entry; final assessment after review (often years later)

Sync case data weekly from Commerce.gov / customsmobile.com

7.3 PGA hold workflow

CBP / PGA inspector flags hold; status returned via UC message with hold reason code

M4-US updates entry status to &quot;Hold&quot;; pga_hold_flag = 1

Notification dispatched to broker user via M27

Broker uploads PGA-required documents (PN, certificates, lab reports) via M21 Doc Mgmt

Broker submits PGA Message Set update via ABI

PGA reviews; releases or escalates to exam

On release: ULP receives UC update with status &quot;Released&quot;; entry proceeds

12. Security and Audit

12.1 PII / sensitive data handling

EIN: stored encrypted at rest using Azure Key Vault keys; redacted to last-4 in logs

SSN (last 4 only, when used): never store full SSN

Credit card / bank account: not stored by M4-US (handled by M17)

Power of Attorney documents: WORM storage in M21 with 5-year retention minimum

12.2 Audit trail

Per CBP recordkeeping requirements (19 CFR 163), the following are retained for 5 years from entry date:

All ABI messages (sent and received)

Form 7501 PDFs as filed

Commercial invoices, packing lists, BLs, certificates of origin

PGA-related documents

User actions: who created entry, who submitted, who modified

Bond filings and modifications

C-TPAT data: tenant can register as C-TPAT importer; M4-US tags C-TPAT entries

Trusted Trader / FAST: similar tagging support
